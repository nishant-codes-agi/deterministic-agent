Methodology

This analysis identifies anomalous trading days using Z-score analysis of daily returns:

  • Daily Return: Calculated as (Close_today - Close_yesterday) / Close_yesterday
  • Z-Score: (Daily_Return - Mean_Return) / Standard_Deviation_Return
  • Anomaly Threshold: |Z-Score| > 2.0 (approximately 95% confidence interval)

Days with Z-scores beyond ±2.0 are considered anomalous, representing unusually large price movements relative to the recent trading pattern.
